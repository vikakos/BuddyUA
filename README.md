# BuddyUA 🇺🇦

BuddyUA is a decentralized platform connecting displaced Ukrainian children abroad with student volunteers to preserve their native language through friendly weekly conversations and cultural quests.

### Key Features
- Smart AI Matching: Privacy-first pairing based on shared hobbies (gaming, art, music).
- Mission Room & Safeguarding: Real-time sessions with one-click parental safety stop.
- ECTS Volunteering & Verification: 45-minute anti-fraud timer logging accredited volunteer hours for university students on Solana.
- Gamified Quests: Fun cultural micro-quests and XP rewards for kids.
